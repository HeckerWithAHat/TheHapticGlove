## The Haptic Glove: Low-Cost Wearable Control for Universal Accessibility

**The Haptic Glove** is an innovative, low-cost wearable remote designed to empower individuals with disabilities and mobility limitations. By using intuitive finger-to-palm contacts, users can manage smart devices and interact with the internet without the need for significant physical movement or expensive specialized equipment.

**Our Mission:** To provide a non-obstructive, affordable solution that restores independence and control to daily life for those dealing with paralysis or dexterity issues.

## The Problem

For many disabled adults, managing their environment is a significant challenge. While remote controls are crucial for independence, traditional solutions often fall short:  

- Accessibility Barriers: Many individuals with paralysis are unable to use standard remotes or manual interfaces.
- Prohibitive Costs: Existing tools for mobility assistance are often prohibitively expensive.
- Life Interference: Many assistive devices are bulky and interfere with other daily activities.

The Haptic Glove addresses these issues by being low-cost, invisible in daily work until needed, and highly adaptable.

## Features

- **Custom API & Operating System:** Includes a robust OS and an intuitive API, allowing developers to easily create new "apps" for the glove.
- **E-Paper Interface:** A low-power E-Paper display provides clear visual feedback and app selection, such as Spotify or IoT controls.
- **Haptic Shortcuts:** Uses metal/Faraday fabric contacts on the fingers that act as shortcuts for running user-defined apps.
- **IoT Integration:** Designed to integrate seamlessly with smart devices and the Internet of Things (IoT) for greater ease-of-access.
- **Non-Obstructive Design:** Iteratively tested to ensure the glove remains sleek and does not hinder natural movement during daily use.

## The Engineering Solution

The project utilizes a combination of affordable, off-the-shelf hardware and custom software to create a functional prototype.

### Materials

- 1 Pair of Gloves: Standard fabric gloves for comfort.
- Raspberry Pi Zero 2 W: The core processing unit.
- E-Paper Display: For the user interface.
- Faraday Fabric: Used for durable, conductive finger contacts.
- Standard Wires & Tape: For internal cabling and securing components.

### Prototype Evolution

1. **Early Versions:** Initially tested with latex and rubber gloves using breadboards and Raspberry Pi units.
2. **Iterative Improvements:** Transitioned to fabric gloves to fix "loose" fit issues and moved from Pi Pico (MicroPython) back to the more robust Zero 2 W.
3. **Final Prototype:** Features soldered Faraday fabric contacts and an integrated E-Paper screen for a more streamlined experience.

## How We Are Unique

The Haptic Glove fills a unique gap in the market. Unlike specialized devices like the Global DJ or VR controllers, our goal is a general-purpose accessibility tool. It is a more accessible and open-ended alternative to shelved projects like the Gest, providing a developer-friendly platform for real-world assistance.

## Steps to Use DependGuard

1. **Wear the Device:** The fabric glove is designed to be comfortable for all-day wear.
2. **Select an App:** Use the E-Paper display to navigate through installed tools (e.g., Spotify).
3. **Trigger Actions:** Touch the finger contacts to your palm to execute specific commands or shortcuts.
4. **Develop New Tools:** Use the provided API to build custom sample apps tailored to specific mobility needs.

## Next Steps & Reflection

We are constantly looking to improve the Haptic Glove's functionality:

- **Custom PCB:** Future versions will replace loose cabling with a custom PCB to combine the Pi Zero, E-Paper, and battery into a sleek unit.
- **Ambidextrous Support:** Development of a left-hand glove to allow for dual-hand controllers.
- **Direct Sewing:** We plan to sew Faraday fabric directly into the cloth for even better finger mobility.
